 다른 패키지 클래스를 가져오기  

 데이터와 이를 관리하는 메서드로 구성된 구조를 선언한 설계도  

 모든 클래스에서 변수나 메소드 등에 접근할 수 있도록 허용  

 해당 클래스 내에만 변수나 메소드 등에 접근할 수 있도록 허용  

 객체 자신에 대한 레퍼런스  

 클래스 객체를 메모리에 생성  

 메서드 종료시 제어흐름이 메서드를 호출했던 곳으로 되돌아감  

 해당 객체를 문자열로 변환하는 메서드  

 비교연산자로 두 변수값이 같으면 참을 반환하고 다르면 거짓을 반환  

 클래스 객체의 데이터 값과 전달인자의 데이터 값을 비교하여 같으면 참을 반환하고 다르면 거짓을 반환  

 클래스 객체의 데이터 값과 전달인자의 데이터 값을 비교한 차이를 반환하며, 같으면 0을 반환  

 수학과 관련된 다양한 메서드를 제공해주는 클래스  

 제곱근 결과를 반환하는 메서드  

 밑수의 지수승을 반환하는 메서드  

 조건식이 참이면 해당 명령문을 실행하는 선택문  

 앞에 제시된 조건식이 모두 거짓이면 해당 명령문을 실행하는 선택문  

 논리연산자 AND는 왼쪽과 오른쪽 조건식이 둘 다 모두 참이면 참을 반환하고, 나머지는 거짓을 반환
