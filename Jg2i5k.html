문제

아래 설명된 의미에 해당하는 용어를 쓰세요 
 클래스로 생성된 모든 객체 인스턴스에서 사용할 수 있는 변수이며, 클래스에서 정적으로 공간을 확보  

 클래스내 모든 메서드에서 사용할 수 있는 변수이며, 객체 인스턴스를 생성할 때 공간을 확보  

 함수 내부에서만 사용할 수 있는 변수이며, 함수 호출시 공간을 확보하고 함수 종료시 소멸  

 정적 선언 키워드로 정적 공간은 한번 생성되면 프로그램 시작할 때부터 종료시까지 사용 가능  

 데이터와 이를 관리하는 메서드로 구성된 구조를 선언한 설계도  

 모든 클래스에서 변수나 메소드 등에 접근할 수 있도록 허용  

 해당 클래스 내에만 변수나 메소드 등에 접근할 수 있도록 허용  

 객체 자신에 대한 레퍼런스  

 클래스 객체를 메모리에 생성  

 메서드 종료시 제어흐름이 메서드를 호출했던 곳으로 되돌아감  

 해당 객체를 문자열로 변환하는 메서드  

 초기식, 조건식, 증감식으로 구성되고, 조건식이 참일 때마다 해당 명령문을 실행하는 반복문  

 조건식이 참이면 해당 명령문을 실행하는 선택문  

 앞에 제시된 조건식이 모두 거짓이면 해당 명령문을 실행하는 선택문  

 복합대입연산자로 연산자의 왼쪽 변수값에 오른쪽 값만큼 더한 값을 왼쪽 변수 공간에 저장  

 비교연산자로 두 변수값이 같으면 참을 반환하고 다르면 거짓을 반환  

 논리연산자 OR로 왼쪽과 오른쪽 조건식중 하나라도 참이면 참을 반환하고, 둘 다 거짓이면 거짓을 반환
